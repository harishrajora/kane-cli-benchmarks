Complete every item before deploying to production.

- [ ] All CI checks pass on the release branch
- [ ] Deployed to [Staging](page:deployment-runbook/staging) for at least 24 hours
- [ ] Release notes drafted
- [ ] Database migrations reviewed by a second engineer
- [ ] On-call engineer informed
- [ ] Deploy to production between 09:00 and 15:00 UTC, Monday to Thursday

Releases are never deployed on Fridays.
